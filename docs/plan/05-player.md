# 플레이어 시스템

## 1. 플레이어 개입
*   **기본 방향:** 관찰 중심 게임이므로 개입은 최소화가 이상적이나, 플레이어 취향에 따라 개입 수준을 열어둠.
*   **캐릭터 말풍선 이벤트:** 캐릭터가 말풍선을 띄우면 플레이어가 반응할 수 있음.
    *   관계 고민 상담 (방향 제시 → AI가 의도 파악해 최종 행동 결정).
    *   요구사항 들어주기 (아이템, 음식 등).
    *   미니게임 참여.
*   **물리적 간섭:** 캐릭터를 집어서 다른 캐릭터 옆에 배치 → 만남/상호작용 유도 (최종 반응은 캐릭터 성격에 따라 AI가 결정).
*   **펫 상호작용:** 쓰다듬기 등 직접 인터랙션.
*   **아이템 선물:** 캐릭터 페르소나에 기반한 동적 반응.

## 2. 경제 시스템
*   **돈 관리:** 플레이어가 직접 관리. 캐릭터가 자율적으로 소비하지 않음.
*   **구매 흐름:** 플레이어가 상점(식료품점, 의류점, 인테리어점)에서 구매 → 캐릭터에게 지급.
*   **캐릭터 요청:** "이거 먹고 싶어요" / "이거 입고 싶어요" 말풍선 → 플레이어가 들어줄지 선택. LLM이 캐릭터 선호도 기반으로 요청 생성.
*   **수입원:** 모금함 (하루 1회), 미니게임 보상 등.

## 3. 아이템 시스템
*   **초기 범위 (Phase 1~2):** 음식 + 선물용 잡화 (관계에 영향 주는 것 위주).
*   **확장 범위 (Phase 3~4):** 의류, 인테리어, 모자 등 점진 확대.
*   **설계 원칙:** 아이템 스키마를 범용으로 설계 (`{ id, category, name, effect }` 등)하여 카테고리 추가 시 시스템 변경 없이 데이터만 추가.

## 4. 펫 시스템
*   캐릭터의 소유물(오브젝트)로 취급. 펫 자체에 AI 에이전트는 부여하지 않음.
*   **한 캐릭터당 최대 1마리.** 종류는 별도 제한 없음 (추후 결정).
*   **획득 방법:** 입양 등 간단한 방식.
*   **영향 범위:**
    *   대화 소재로 활용 (펫 자랑, 펫 고민 등).
    *   플레이어가 펫과 상호작용 가능 (쓰다듬기 등).
    *   캐릭터 기분에 영향 (돌봄으로 스트레스 해소 등).
