# 플레이어 시스템

## 1. 플레이어 개입
*   **캐릭터 말풍선 이벤트:** 캐릭터가 말풍선을 띄우면 플레이어가 반응할 수 있음.
    *   관계 고민 상담 (아래 상담 시스템 참조).
    *   고백/프로포즈 허락 요청 ("고백하고 싶어요" → "해!" / "하지마").
    *   요구사항 들어주기 (아이템, 음식 등).
    *   미니게임 참여.
*   **물리적 간섭:** 캐릭터를 집어서 다른 캐릭터 옆에 배치 → 만남/상호작용 유도 (최종 반응은 캐릭터 성격에 따라 AI가 결정). 조작: 머리 길게 누르기 → 들어올리기.
*   **펫 상호작용:** 쓰다듬기 등 직접 인터랙션.
*   **아이템 선물:** 캐릭터 페르소나에 기반한 동적 반응.
*   **캐릭터 터치 상호작용:**
    *   **쓰다듬기 (필수):** 만족도 소폭 상승.
    *   **얼굴(머리) 터치:** 랜덤 반응 — 밥풀/벌레 떼주기(→ 만족도↑), 부끄러워함, 윙크 연습 등.
    *   **배 터치:** 별도 기능 검토 중 (TBD).

## 2. 상담/선택지 시스템
캐릭터가 관계에 대해 상담을 요청하면, 플레이어가 선택지를 골라줌. 선택 결과가 수치에 영향.

### 상담 유형
| 상담 내용 | 선택지 예시 | 영향 |
|----------|-----------|------|
| "ㅇㅇ와 친구가 되고 싶은데 어떤 주제로 이야기하면 좋을까요?" | 취미 / 음식 / 날씨 / 운동 등 | 상대 취향에 맞으면 friendship 보너스 |
| "어떤 말투로 말을 걸면 좋을까요?" | 밝게 / 진지하게 / 장난스럽게 / 조용히 등 | 상대 성격에 맞으면 보너스 |
| "ㅇㅇ에게 선물을 주고 싶은데 뭐가 좋을까요?" | 음식 / 액세서리 / 편지 등 | 상대 선호도에 맞으면 friendship/romance 보너스 |
| "고백하고 싶어요" | "해!" / "하지마" / "좀 더 친해지고 나서" | 관계 이벤트 트리거 또는 보류 |
| "ㅇㅇ랑 싸웠어요... 어떡하죠?" | "사과해" / "시간을 둬" / "네가 맞아" | 화해 시도 방식 결정 → 성공률에 영향 |

### 선택지 매칭 로직
*   플레이어의 선택 → 상대 캐릭터의 성격/취향과 매칭 → 보너스 배율 적용.
*   정답이 명확하지 않도록 설계: 같은 상대라도 상황에 따라 최적 선택이 달라짐.
*   **선택지 생성:** 기본 선택지 풀을 미리 만들되, LLM이 상황에 맞는 선택지를 동적으로 생성하는 것도 고려.

## 3. 경제 시스템
*   **돈 관리:** 플레이어가 직접 관리. 캐릭터가 자율적으로 소비하지 않음.
*   **구매 흐름:** 플레이어가 상점(식료품점, 의류점, 인테리어점)에서 구매 → 캐릭터에게 지급.
*   **캐릭터 요청:** "이거 먹고 싶어요" / "이거 입고 싶어요" 말풍선 → 플레이어가 들어줄지 선택. LLM이 캐릭터 선호도 기반으로 요청 생성.

### 수입
*   **모금함:** 하루 1회. 캐릭터 수에 비례.
*   **캐릭터 만족 보상:** 만족도에 비례하여 돈 지급.
*   **미니게임 보상.**

### 가격 체계
*   현실 가격 비율 반영 (김밥 < 라면 < 치킨 < 스테이크).
*   **음식 < 의류 < 인테리어** 순 가격대.
*   등급 표시 없음. 가격 자체가 등급 역할.
*   음식별로 포만감과 가격이 모두 다름.

### 밸런스 방향
*   일반 아이템은 넉넉하게 살 수 있지만, 넘치지는 않게.
*   **레어/고가 아이템:** 비싼 의류, 희귀 인테리어 등 → 모아서 사야 하는 느낌.
*   **초고가 목표 (엔드 콘텐츠):** 천문학적 금액이 필요한 특별 콘텐츠 (ex. 우주여행 등) → 장기 플레이/저축 동기.
*   화폐 단위, 구체적 가격 수치는 추후 결정. (TODO)

## 4. 여행 시스템
*   **여행 티켓:** 아이템으로 캐릭터에게 지급.
*   **일반 상태:** 연인/베프가 있으면 같이 여행. friendship/romance 부스트 + 기념품(아이템) 가져옴.
*   **절망 상태:** 무조건 혼자 여행. 기분 즉시 회복. 기념품 없음.
*   **여행지:** 랜덤 선정 (각 나라 관광지).
*   **사진:** 여행 중 관광지에서 사진 3장 촬영. 가끔 눈 감은 사진이 찍힘. 각 사진 저장 여부 선택 가능 → 사진첩에 보관.
*   여행지 목록, 기념품 목록 등은 추후 설계. (TODO)

## 5. 아이템 시스템
*   **초기 범위 (Phase 1~2):** 음식 + 선물용 잡화 (관계에 영향 주는 것 위주).
*   **확장 범위 (Phase 3~4):** 의류, 인테리어, 모자 등 점진 확대.
*   **설계 원칙:** 아이템 스키마를 범용으로 설계 (`{ id, category, name, effect }` 등)하여 카테고리 추가 시 시스템 변경 없이 데이터만 추가.

### 보물 아이템
*   수집용 잡화. 획득 시 **컬렉션에 자동 등록** (도감).
*   **소장 또는 선물:** 보물을 가지고 있거나, 캐릭터에게 선물 가능.
*   선물 시 선호도 시스템 적용 (좋아하는/싫어하는 보물), 만족도·관계에 영향.
*   **판매:** 돈으로 환산 가능.
*   **LLM 연동:** 캐릭터가 받은 보물을 대화에서 언급 가능 ("그때 받은 거 아직 소중하게 가지고 있어요!").

### 도구 아이템 (확정 목록)
| 아이템 | 효과 |
|--------|------|
| 여행 티켓 | 캐릭터 여행 (연인/베프 동반, 절망 회복 등). 상세: 4. 여행 시스템 |
| 프라이팬 | 캐릭터가 주방에서 랜덤 요리 → 카탈로그 추가 |
| 카메라 | 캐릭터가 사진 찍어옴 (제목 포함). 갤러리 저장 |
| 감기약 | 감기(cold) 치료 |
| 배탈약 | 배탈(stomachache) 치료 |
| 목욕 세트 | 목욕 이벤트 (상세: [03-space-and-events.md](03-space-and-events.md)) |

### 감정 조작 아이템 (레어)
*   **획득 확률 극악** (모금함 대박, 꿈 보상, 여행 기념품 등 초저확률).
*   **효과:** A가 B에 대해 가진 감정을 강제로 조작 (단방향). A→B의 friendship/romance를 변경.
*   **단방향:** 상대(B→A)의 감정은 바뀌지 않음. A가 적극적으로 다가가면 이후 B의 감정도 자연스럽게 변할 수 있음.
*   **횟수 제한 없음.** 다만 아이템 자체가 극악 확률이라 빈번하게 못 씀.
*   "신의 권능" 컨셉 — 플레이어가 관찰자를 넘어 가끔 극적으로 개입.

## 6. 펫 시스템
*   캐릭터의 소유물(오브젝트)로 취급. 펫 자체에 AI 에이전트는 부여하지 않음.
*   **한 캐릭터당 최대 1마리.**
*   **종류 (6종 프리셋):** 강아지, 고양이, 토끼, 햄스터, 새, 거북이.
    *   원작은 직접 그리기였으나 MVP에서는 프리셋만.
*   **획득 경로:**
    *   플레이어가 직접 지급.
    *   캐릭터가 "기르고 싶어요" 말풍선 → 플레이어가 허락/거절.
*   **펫 선호도 (캐릭터 생성 시 랜덤):**
    *   특정 종 선호 (예: 고양이파, 강아지파).
    *   일부 캐릭터는 "펫 무관심" — 안 키우는 게 best. 펫을 받으면 만족도↓.
*   **상호작용:** 최소화. 방에서 볼 수 있음 정도.
*   **종별 이벤트:** 예) 강아지 → "산책 나갔다" 이벤트. 종별 특성 반영.
*   **영향 범위:**
    *   대화 소재로 활용 (펫 자랑, 펫 고민 등).
    *   캐릭터 기분에 영향.
