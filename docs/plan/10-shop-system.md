# 상점 시스템

## 1. 하루 기준
*   새벽 5시에 하루 리셋. 상점 상품 갱신, 모금 리셋 등 모든 일일 기준.

## 2. 상점 목록
*   식료품점, 의류점, 인테리어점.
*   Phase 1~2: 식료품점 위주. Phase 3~4: 의류/인테리어 확장.

## 3. 상품 유형

### Daily
*   매일 새벽 5시에 랜덤 교체.
*   **기념일 아이템:** 특정 날짜에는 기념일 아이템이 Daily 풀에 강제 포함.
*   매일 올라오는 상품 수, 가격 체계 등은 추후 결정.

#### 기념일 목록
| 기념일 | 날짜 | 아이템 예시 |
|--------|------|----------|
| 설날 | 2/1 ~ 2/7 (주간) | 떡국, 한복 |
| 발렌타인데이 | 2/14 | 초콜릿 |
| 화이트데이 | 3/14 | 사탕 |
| 블랙데이 | 4/14 | 짜장면 |
| 어버이날 | 5/8 | 카네이션 |
| 추석 | 9/15 ~ 9/21 (주간) | 송편, 한복 |
| 빼빼로데이 | 11/11 | 빼빼로 |
| 크리스마스 | 12/25 | 케이크 |

*   설날/추석은 음력 계산 대신 고정 주간으로 처리 (구현 단순화).

### Seasonal
*   시즌/이벤트별 한정 상품. 기간 한정 판매.
*   현실 계절 연동 여부는 추후 결정.

### Catalog
*   한번 입수(구매 또는 기타 방법으로 획득)한 아이템은 이후 언제든 재구매 가능.
*   상시 접근 가능.
