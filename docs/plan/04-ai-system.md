# AI 시스템

## 1. AI 자율성 및 이벤트 시스템
*   **이벤트 빈도 조절:** 플레이어가 마을 분위기를 선택 가능 (예: "느긋한 마을" / "시끌벅적한 마을"). AI의 자율 행동 빈도와 이벤트 발생률을 조절.
*   **높은 자율성:** AI 에이전트가 플레이어 개입 없이도 자발적으로 관계를 형성하고 이벤트를 발생시킴.

## 2. 시뮬레이션 전략
*   **플레이어 접속 중:** 실시간 진행. 랜덤 간격으로 이벤트 발생 → LLM 호출 → 대사 생성 → 화면 표시.
*   **플레이어 부재 시:** 시뮬레이션 정지. 다음 접속 시 부재 시간을 계산하여 **Catch-up 처리:**
    *   숫자 테이블만으로 "그 사이에 일어났을 법한 이벤트"를 경량 산출 (LLM 호출 없이).
    *   결과를 이벤트 로그에 기록.
    *   접속 시 뉴스 브리핑(자동 재생)으로 하이라이트 요약 + 캐릭터별 말풍선으로 세부 사정 확인 가능.
    *   큰 이벤트(고백, 결혼 등)는 부재 중 보류 → 접속 시 말풍선으로 대기 (상세: [02-relationship.md](02-relationship.md) 참조). 사소한 이벤트만 생성.
    *   **상한:** 부재 기간과 무관하게 하루 3~5건 수준. 수치 변화 + 이벤트 로그 기록만, 말풍선 없음.

## 3. LLM 호출 전략
*   24명 전원이 동시에 LLM을 호출하지 않음.
*   이벤트 대상 캐릭터는 **기존 게임처럼 확률/조건 기반으로 랜덤 선정** (숫자 테이블이 트리거).
*   선정된 캐릭터의 대사/반응 생성에만 LLM 호출 → 이벤트당 1~2회 수준으로 관리.

## 4. LLM 프로바이더
*   litellm 기반으로 **어떤 프로바이더든 지원 가능**. 코드에서 litellm / claude-cli / codex-cli 3개 provider 구현 완료.
*   **기본 타겟:** 로컬 Ollama (gemma-4, qwen3.5 등 8B~14B급 모델). 개발 환경: RTX 4070Ti (VRAM 12GB).
*   ⚠️ 로컬 Ollama 사용 시, 모바일 접속 시에는 서버 PC가 켜져 있어야 함.

## 5. 음성 시스템 (TTS)
*   **기본 엔진:** Web Speech API (브라우저 내장, 무료). 원작도 어설픈 로봇 음성이었으므로 톤이 맞음.
*   **초기 구현:** 남자/여자 목소리 프리셋 2종만. 성별에 따라 자동 배정.
*   **이후 확장:** 성격별 pitch/rate 세부 조정 (활발 → pitch↑ rate↑, 차분 → pitch↓ rate↓ 등).
*   **대안 (필요 시):** Piper, Kokoro TTS (로컬, 무료, 더 자연스러운 음성).

## 6. 뉴스 시스템
*   아나운서 캐릭터가 한 건씩 브리핑. 스킵 가능.
*   **최초 접속 시:** 실제 이벤트 1건 브리핑 (캐릭터 생일, 관계 변화 등 catch-up에서 생성된 하이라이트).
*   **이후 추가 시청:** 플레이어가 또 누르면 랜덤 병맛 뉴스 (마을/관계와 무관한 쓸데없는 뉴스). LLM 또는 템플릿 풀에서 생성.

## 7. 꿈 시스템
*   **템플릿 기반:** 미리 만든 꿈 템플릿 풀에서 랜덤 선택. 캐릭터 이름/관계 등 변수만 치환. 병맛 필수.
*   **꿈별 보상 아이템 매핑:** 각 꿈 템플릿에 연결된 보상 아이템(보물/음식/옷 등)이 있음.
*   **보상 조건:**
    *   밤 수면 중 꿈 → 보상 아이템 지급.
    *   낮잠 / 최면술 도구로 본 꿈 → 꿈만 보고 보상 없음.
