# LLM 사용 범위

## 1. LLM 사용/템플릿 경계

### LLM 사용
| 상황 | 입력 맥락 | 비고 |
|------|----------|------|
| 캐릭터 간 대화 | 성격, 슬라이더 강도, 미니 개성, 말버릇, 별명, 관계(슬롯+수치+태그), 기억, 장소, 시간대, 기분, 가드레일 | 핵심 차별점 |
| 고백/이별/프로포즈 대사 | 위 + 이벤트 사유, 이벤트 로그 | 서사적 깊이 |
| 질투/싸움 행동 | 성격, 관계, 질투 대상/라이벌 정보 | 매번 다른 표현 |
| 뉴스 브리핑 (실제 이벤트) | 당일 이벤트 로그 요약 | 접속 시 1건 |
| 뉴스 브리핑 (병맛) | 없음 (자유 생성) | 추가 시청 시 |
| 랩배틀 | 성격, 관계 | 디스 라임 생성 |
| 끝말잇기 | 아이템 풀 목록 | 단어 선택 |
| 상담 응답 | 성격, 관계, 상담 내용, 선택지 | 맥락 반영 |
| 아무말 대잔치 (...말풍선) | 성격, 관계(연인/친구 정보), Overall(특이↔평범), 최근 기억 | 연인 이야기, 친구 이야기, 엉뚱한 소리 등 |
| 특정 아이템 지목 요청 | 성격, 선호도, 최근 본 아이템 | "어제 본 그 케이크..." |
| 노래 가사 생성 | 분위기 입력 또는 랜덤 | 장르별 |

### 템플릿 사용
| 상황 | 조합 기준 | 비고 |
|------|----------|------|
| 방 방문 인사 | 성격별 × 시간대별 × 상황(기분, 배고픔 등) | 정형화된 인사 |
| 일반 요구사항 | "배고파요", "옷 입고 싶어요" 등 | 아이템 지목은 LLM |
| 꿈 | 꿈 템플릿 풀에서 랜덤 + 변수 치환 | 병맛 |
| 음식 리액션 | 선호 구간별 연출 (5단계) | 연출 중심 |
| 미니게임 대사 | 승/패 반응 | 짧고 정형화 |

## 2. 공통 입력 맥락 블록

LLM 호출 시 상황에 따라 조합하여 사용하는 맥락 블록:

| 블록 | 내용 |
|------|------|
| 캐릭터 기본 | 이름, 성격 유형, 슬라이더 값(강도), Overall(특이↔평범), 미니 개성, 말버릇(감정별 5종) |
| 관계 | 상대와의 friendship/romance, 관계 슬롯(베프/연인/원수), 전 연인 태그(사유 포함), 별명 |
| 기억 | 최근 이벤트 로그 (상대와의 공유 기억 n건) |
| 상태 | 현재 기분, 만족도, 배고픔 |
| 상황 | 장소, 시간대 |
| 가드레일 | "우정이 깊어진다고 반드시 연애로 발전하지는 않는다" 등 |

*   모든 블록을 매번 넣지 않음. 상황에 필요한 블록만 선택 주입.
*   구체적인 프롬프트 포맷과 출력 형식은 코드 단에서 설계.

## 3. 판단 이벤트 (LLM이 결정을 내리는 경우)

관계 전환 등 **결정이 필요한 이벤트**는 LLM이 맥락 기반으로 판단. 수치는 퍼지하게 전달 (`friendship 78` → `"꽤 친한 편"`), temperature 0.8~1.0로 자연스러운 편차.

### 한쪽 결심 이벤트 (LLM이 한 캐릭터 입장에서 판단)
*   고백 시도, 고백 수락/거절
*   프로포즈 시도, 프로포즈 수락/거절
*   이별 통보
*   화해 시도
*   바람 (제3자에게 넘어갈지)
*   입력: 결심하는 캐릭터 입장에서의 맥락 (성격, 관계, mood, 시간/장소, 히스토리)
*   출력: 결정 + 이유 (이유는 대사 생성에 반영)

### 쌍방 이벤트 (LLM이 두 캐릭터의 상호작용으로 판단)
*   싸움 발생 (둘 사이의 긴장이 임계값 넘을 때, 어떻게 부딪힐지)
*   싸움 결과 (누가 먼저 말 걸지, 어떻게 풀지)
*   입력: 두 캐릭터 전체 맥락
*   출력: 두 캐릭터의 대사 + 행동 + 감정 변화

### 대안: 공식 + 계수 랜덤 + 상황 가중치 (LLM 미사용)
*   LLM이 기대와 다르게 나올 경우 공식으로 **완전 전환** (혼합 아님).
*   3단 구조: 계수 랜덤 공식 → 상황 가중치 보정 → 최종 랜덤 판정
*   일반 게임 구현 패턴("가중치 확률 테이블 + 조건 기반 공식")의 혼합.
*   구체적 수치(계수 범위, 보정값 등)는 미확정. 구현 시 조정.
*   상세: [02-relationship.md](02-relationship.md) 고백/프로포즈 판단 방식 참조.
