# 세이브 시스템

## 1. 수동 저장
*   플레이어가 직접 저장. 자동 저장 없음 (관계 흐름의 자연스러움 유지).
*   **복수 슬롯** 지원. 슬롯 수는 추후 결정.

## 2. 크래시 대비 (임시 보관)
*   탭 닫힘/크래시 감지 → 임시 데이터 저장. (브라우저: `beforeunload` + localStorage, Godot: `NOTIFICATION_WM_CLOSE_REQUEST` + `user://` 등 플랫폼별 구현 고려 중)
*   다음 접속 시 비정상 종료 감지되면 팝업: "비정상 종료가 감지되었습니다. 임시 데이터를 복구할까요?"
    *   복구 → 임시 데이터로 이어서 플레이.
    *   복구 안 함 → 마지막 수동 저장에서 시작.
*   자동 저장과 달리 되돌리기 남용 불가. 크래시 안전망 역할만.

## 3. 저장 포맷
*   로컬 저장 (JSON 또는 SQLite). 구체적인 포맷은 구현 단계에서 결정.
