# UI/UX & 설정

## 1. UI/UX
*   기존 토모다치 시리즈의 화면 흐름을 기본으로 참고.
*   우선 구현 후 직접 플레이하면서 불편한 점을 이터레이션으로 개선.
*   상세 화면 설계는 프론트엔드 Phase에서 진행.

## 2. 설정 화면
*   **기본 설정 (초기 구현):**
    *   볼륨 조절 (BGM / 효과음 / TTS)
    *   키 매핑
    *   오전/오후 반전 모드 토글
    *   이벤트 빈도 조절 ("느긋한 마을" / "시끌벅적한 마을")
    *   LLM 프로바이더 / 모델 / API 키 설정
*   이후 필요에 따라 항목 추가.
