# 공간 & 이벤트 시스템

## 1. 공간 시스템
*   **공동주택 (셰어하우스 형태):**
    *   **개인 방:** 캐릭터 1인 1실. 인테리어(방 통째 교체), 수면, 개인 이벤트. 결혼 시 인접 방 합쳐서 2인 공유. 이혼 시 원래 방으로 복귀.
    *   **공유 주방:** 음식 먹는 곳. 캐릭터끼리 자연스럽게 마주치는 만남 이벤트.
    *   **공유 거실:** TV, 수다, 여러 명 모임.
    *   **발코니:** 혼자 생각, 1:1 대화, 밤 이벤트, 고백 장소 후보.
    *   한눈에 전체 캐릭터 상태(말풍선 등) 확인 가능.
*   **다중 섬 (공간 분리):** 섬을 여러 개 만들어서 캐릭터 그룹을 분리 배치할 수 있음. **한 섬당 최대 24명.** 섬 간 캐릭터 이동/교류 여부는 추후 결정.

### 개인 방 상세
플레이어가 캐릭터의 방을 방문했을 때:

**상단 표시:** 만족도, 포만감, 관계 목록 (베프/연인/원수 + 상태 텍스트)

**할 수 있는 것:**
*   선물 주기 (음식, 옷, 인테리어, 아이템 등)
*   옷 바꾸기
*   인테리어 바꾸기
*   말버릇 바꾸기
*   노래 시키기 → 콘서트홀로 이동

**말풍선 이벤트 (캐릭터 상태에 따라 발생):**
*   집 외관(문/굴뚝 등)에서 말풍선 표시 → 들어가기 전에 이벤트 유무 확인 가능.
*   **유지 시간:** 약 10분. 이후 자동 소멸.
*   종류:
    *   고민 상담 (관계 고민, 일상 고민 등)
    *   미니게임 제안 ("같이 놀아요!")
    *   고백/프로포즈 허락 요청
    *   요구사항 ("이거 먹고 싶어요", "배고파요" 등)
    *   잠든 캐릭터 → 꿈 말풍선 표시 시 꿈 이벤트 진입 가능

## 3. 캐릭터 동선
*   **목표:** 캐릭터가 섬 맵 위를 실제로 돌아다니며 장소를 방문하는 시각적 표현.
*   **동선 결정:** 시간표 없이 조건 기반 랜덤. 매 틱 다음 조건을 확률적으로 평가:
    *   도구/아이템이 있으면 → 관련 장소 방문 확률↑
    *   친구/베프/연인이 있으면 → 상대가 있는 장소로 가거나, 놀러오기
    *   배고프면 → 집에서 "배고파요" 말풍선
    *   특별한 조건 없으면 → 완전 랜덤
*   **단계적 구현:**
    *   Phase 1~2: 장소 상태 표시 ("A는 카페에 있다") + 이벤트 시 해당 장소 배경 연출.
    *   Phase 3~4: 맵 위 캐릭터 이동 애니메이션 추가.

*   **실시간 연동:** 현실 하루 = 게임 하루. 서�� 게임 컨셉에 맞는 느긋한 진행.
*   **틱 없음.** 실시간으로 흘러가며 이벤트가 랜덤 간격으로 자연스럽게 발생.
*   **시간대 구분:** 현실 시간에 맞춰 아침/낮/저녁/밤 정도만 구분. 배경 변화, 밤에는 캐릭터 취침. 특정 이벤트는 시간대에 따라 발생 (아침 장터, 밤 꿈 등).
*   **이벤트 발생:** 일정 간격(ex. 10~30분)마다 랜덤 체크 → 조건 충족 시 발생. 발생 빈도는 이벤트 빈도 설정에 따라 조절.
*   **하루 리셋:** 새벽 5시 (상점 갱신, 모금 리셋 등 모든 일일 기준).
*   **오전/오후 반전 모드:** 밤에 플레이하는 유저가 낮 이벤트를 놓치지 않도록 시간대를 12시간 반전하는 옵션 제공.

## 5. 엔딩 크레딧
*   **최초 결혼 달성 시** 엔딩 크레딧 재생. 클리어가 아닌 "첫 마일스톤 축하" 성격. 이후 게임은 계속 진행.

## 6. 이벤트 시스템
*   **모금:** 하루 1회 필수. 분수대에서 진행.
*   **장소별 이벤트 풀:** 각 장소에 성격에 맞는 이벤트 풀을 배정. 원작처럼 고정 시간대가 아닌 **랜덤 발생**.
*   **관찰/참여:** 이벤트 성격에 따라 다름 (관찰만 하는 것, 플레이어가 참여할 수 있는 것).
*   세부 이벤트 목록은 장소 확정 후 설계. 원작 이벤트 참고는 [07-research.md](07-research.md).

## 6. 미니게임
두 트랙으로 구분. 구체적인 게임 목록은 추후 설계.

### 관찰형 (캐릭터끼리)
*   플레이어는 구경만. 결과가 관계/기분에 영향.
*   예시 방향: 끝말잇기, 랩 배틀, 가위바위보, 요리 대결 등.

### 참여형 (플레이어 + 캐릭터)
*   캐릭터가 "나랑 놀아줘" 말풍선으로 유도. 간단한 터치/클릭 기반.
*   원작 참고: 모기 잡기, 무궁화 꽃이 피었습니다 등.
*   새로운 미니게임을 독자적으로 기획.
