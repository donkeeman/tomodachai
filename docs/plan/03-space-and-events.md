# 공간 & 이벤트 시스템

## 1. 공간 시스템
*   **공동주택 (셰어하우스 형태):**
    *   **개인 방:** 캐릭터 1인 1실. 인테리어(방 통째 교체), 수면, 개인 이벤트. 결혼 시 인접 방 합쳐서 2인 공유. 이혼 시 원래 방으로 복귀.
    *   **공유 거실:** 소파 수다, TV 시청, 여러 명 모임, 미니게임.
    *   **발코니:** 혼자 생각, 1:1 대화, 밤 이벤트, 고백 장소 후보.
    *   ~~주방: 보류. 도구 아이템(프라이팬 등) 활용 장소로 필요 시 추가 검토.~~
    *   한눈에 전체 캐릭터 상태(말풍선 등) 확인 가능.
*   **다중 섬 (공간 분리):** 섬을 여러 개 만들어서 캐릭터 그룹을 분리 배치할 수 있음. **한 섬당 최대 24명.** 섬 간 캐릭터 이동/교류 여부는 추후 결정.

### 개인 방 상세
플레이어가 캐릭터의 방을 방문했을 때:

**상단 표시:** 만족도, 포만감, 관계 목록 (베프/연인/원수 + 상태 텍스트)

**할 수 있는 것:**
*   선물 주기 (음식, 옷, 인테리어, 아이템 등)
*   옷 바꾸기
*   인테리어 바꾸기
*   말버릇 바꾸기
*   노래 시키기 → 콘서트홀로 이동
*   액자 사진 변경 (갤러리에서 선택)

**말풍선 이벤트 (캐릭터 상태에 따라 발생):**
*   집 외관(문/굴뚝 등)에서 말풍선 표시 → 들어가기 전에 이벤트 유무 확인 가능.
*   **유지 시간:** 약 10분. 이후 자동 소멸.
*   종류:
    *   고민 상담 (관계 고민, 일상 고민 등)
    *   미니게임 제안 ("같이 놀아요!")
    *   고백/프로포즈 허락 요청
    *   요구사항 ("이거 먹고 싶어요", "배고파요" 등)
    *   잠든 캐릭터 → 꿈 말풍선 표시 시 꿈 이벤트 진입 가능

## 3. 캐릭터 동선
*   **목표:** 캐릭터가 섬 맵 위를 실제로 돌아다니며 장소를 방문하는 시각적 표현.
*   **동선 결정:** 시간표 없이 조건 기반 랜덤. 일정 간격으로 다음 조건을 확률적으로 평가:
    *   도구/아이템이 있으면 → 관련 장소 방문 확률↑
    *   친구/베프/연인이 있으면 → 상대가 있는 장소로 가거나, 놀러오기
    *   배고프면 → 집에서 "배고파요" 말풍선
    *   특별한 조건 없으면 → 완전 랜덤
*   **단계적 구현:**
    *   Phase 1~2: 장소 상태 표시 ("A는 카페에 있다") + 이벤트 시 해당 장소 배경 연출.
    *   Phase 3~4: 맵 위 캐릭터 이동 애니메이션 추가.

## 4. 시간 ��스템
*   **실시간 연동:** 현실 하루 = 게임 하루. 서�� 게임 컨셉에 맞는 느긋한 진행.
*   **틱 없음.** 실시간으로 흘러가며 이벤트가 랜덤 간격으로 자연스럽게 발생.
*   **시간대 구분:** 현실 시간에 맞춰 아침/낮/저녁/밤 정도만 구분. 배경 변화, 밤에는 캐릭터 취침. 특정 이벤트는 시간대에 따라 발생 (아침 장터, 밤 꿈 등).
*   **이벤트 발생:** 일정 간격(ex. 10~30분)마다 랜덤 체크 → 조건 충족 시 발생. 발생 빈도는 이벤트 빈도 설정에 따라 조절.
*   **하루 리셋:** 새벽 5시 (상점 갱신, 모금 리셋 등 모든 일일 기준).
*   **오전/오후 반전 모드:** 밤에 플레이하는 유저가 낮 이벤트를 놓치지 않도록 시간대를 12시간 반전하는 옵션 제공.

## 5. 장소별 이벤트

### 시청 (주민센터) 상세

**기능:** 주민 목록, 추가, 수정, 삭제, trait map, 관계도 그래프.

**관계도 그래프:**
*   **전체 보기:** 24명 전원 노드 + 주요 관계(베프/연인/원수) 엣지만 표시. 전체 구도 파악용.
*   **개인 보기:** 노드 클릭 → 해당 캐릭터 중심으로 연결된 관계만 표시 + 상태 텍스트 상세.
*   엣지 구분: 색상/스타일로 관계 종류 표현 (베프, 연인, 원수, 전 연인 점선 등).

### 공원 (방향성)
*   일상 이벤트 중심: 산책, 벤치 수다, 운동 등.
*   상성 진단 + 랭킹 보드 상시 접근 가능.

### 기타 장소
*   **카페:** 소규모 수다.
*   **해변:** 감성 이벤트.
*   **놀이공원:** 소규모 이벤트.
*   **콘서트홀:** 노래 공연 (01-character.md 노래 시스템 참조).
*   **공동주택 거실:** 소파 수다, TV, 미니게임.
*   **공동주택 발코니:** 1:1 대화, 고백, 밤 이벤트.
*   세부 이벤트는 구현하면서 추가.

### 사진관 상세
**촬영 경로:**
*   사진관에서 직접 촬영
*   여행 중 사진 (3장)
*   카메라 아이템을 캐릭터에게 지급 → 캐릭터가 찍어옴 (제목도 지음)
*   스크린샷 저장 여부는 검토 중

**갤러리:** 사진관에서 모든 사진을 모아보기 (플레이어 열람용).

**액자:** 캐릭터 방에 사진 1장 걸 수 있음.

### 실시간 관찰 이벤트
말풍선 없이 **상호작용 중에 발견**할 수 있는 이벤트. 관찰형 게임의 핵심.
*   **사랑에 빠지는 순간:** 대화 중 배경이 핑크색으로 변하고, 해당 캐릭터가 놀란 표정 + 말을 못함. 상대는 계속 이야기. 이후 플레이어에게 고민 상담 말풍선.
*   **싸움:** 실시간으로 벌어짐. 플레이어가 목격 시 "말린다"/"지켜본다" 선택.
*   **질투 행동:** 회피, 시비 등을 실시간으로 관찰 가능.
*   **일상 대화:** 거실/공원 등에서 캐릭터끼리 대화하는 모습을 관찰.
*   **놓친 경우:** 플레이어가 해당 장면을 안 보고 있었으면, 이후 말풍선으로 폴백 전달.

### 방 방문 이벤트
*   캐릭터가 다른 캐릭터의 방에 놀러감. 1:1 또는 소수(2~3명).
*   **조건:** 지인 이상 (한번이라도 만난 적 있으면). 초면(모르는 사이)은 불가.
*   거실(공개)과 달리 **프라이빗한 대화** — 비밀, 고민, 연애 상담 등 깊은 이야기. LLM에 "프라이빗한 자리" 맥락 전달.
*   플레이어가 해당 방에 들어가면 방문 중인 장면을 볼 수 있음.

### 생일 이벤트
*   캐릭터 생일 당일 (하루 리셋 기준):
    *   **뉴스 속보:** 접속 시 생일 축하 뉴스 브리핑.
    *   **생일 축하 노래:** 공동주택 거실에서 다른 캐릭터들이 축하 노래 부르는 이벤트.
    *   **생일 대사:** 해당 캐릭터 방 방문 시 "오늘 제 생일이에요!" 말풍선.
    *   **포장 선물:** 생일 당일에만 아이템을 포장해서 줄 수 있음 (생일 캐릭터 한정). 일반 선물보다 만족도 보너스↑.

## 6. 엔딩 크레딧
*   **최초 결혼 달성 시** 엔딩 크레딧 재생. 클리어가 아닌 "첫 마일스톤 축하" 성격. 이후 게임은 계속 진행.

## 7. 이벤트 시스템
*   **모금:** 하루 1회 필수. 분수대에서 진행.
*   **장소별 이벤트 풀:** 각 장소에 성격에 맞는 이벤트 풀을 배정. 원작처럼 고정 시간대가 아닌 **랜덤 발생**.
*   **관찰/참여:** 이벤트 성격에 따라 다름 (관찰만 하는 것, 플레이어가 참여할 수 있는 것).
*   세부 이벤트 목록은 장소 확정 후 설계. 원작 이벤트 참고는 [07-research.md](07-research.md).

## 8. 미니게임

### 설계 공식
*   규칙이 10초 안에 이해됨
*   3~5번 안에 끝남 (짧고 반복 가능)
*   캐릭터 반응이 과장됨 (성공 → 극적 기뻐함, 실패 → 극적 실망)
*   간단하면서도 병맛 요소 포함

### 관찰형 (캐릭터끼리)
*   플레이어는 구경만. 결과가 관계/기분에 영향.
*   확정: 랩배틀 (LLM), 끝말잇기 (LLM + 아이템 풀) — 분수대 이벤트.
*   추가 후보는 구현하면서 설계.

### 참여형 (플레이어 + 캐릭터)
*   캐릭터가 "나랑 놀아줘" 말풍선으로 유도. 간단한 터치/클릭 기반.

| 모기 잡기 | 얼굴 위 모기 터치, 5번 안에 |
| 참참참 | 방향 맞추기, 5번 안에 |
