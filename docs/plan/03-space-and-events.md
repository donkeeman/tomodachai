# 공간 & 이벤트 시스템

## 1. 공간 시스템
*   **개별 주택:** 캐릭터마다 자신의 집을 소유 (아파트 일괄 거주가 아닌 개별 공간).
*   **다중 섬 (공간 분리):** 섬을 여러 개 만들어서 캐릭터 그룹을 분리 배치할 수 있음. **한 섬당 최대 24명.** 섬 간 캐릭터 이동/교류 여부는 추후 결정.

## 2. 장소 목록

### 필수 (확정)
| 장소 | 성격 |
|------|------|
| 개별 주택 | 캐릭터 개인 공간 |
| 식료품점 | 음식 구매 |
| 의류점 | 의상 구매 |
| 인테리어점 | 방 꾸미기 |
| 분수대 | 모금(하루 1회 필수), 랜덤 이벤트 |
| 방송국 | 동네 뉴스 브리핑 |

### 후보 (검토 중)
| 장소 | 성격 | 예상 이벤트 |
|------|------|-----------|
| 공원 | 야외 여가 | 산책, 운동, 피크닉, 우연한 만남 |
| 카페 | 소규모 수다 | 2~4명 대화, 고민 토로 |
| 해변/강변 | 감성 장소 | 고백, 혼자 생각, 산책 |
| 광장 | 대규모 모임 | 투표, 공연, 집단 이벤트 |
| 콘서트홀 | 공연 | 노래, 악기 연주 |

## 3. 캐릭터 동선
*   **목표:** 캐릭터가 섬 맵 위를 실제로 돌아다니며 장소를 방문하는 시각적 표현.
*   **동선 결정:** 성격, 관계, 시간대, 기분 등에 따라 방문할 장소를 확률적으로 결정.
*   **단계적 구현:**
    *   Phase 1~2: 장소 상태 표시 ("A는 카페에 있다") + 이벤트 시 해당 장소 배경 연출.
    *   Phase 3~4: 맵 위 캐릭터 이동 애니메이션 추가.

## 4. 시간 시스템
*   **실시간 연동:** 현실 하루 = 게임 하루. 서브 게임 컨셉에 맞는 느긋한 진행.
*   **오전/오후 반전 모드:** 밤에 플레이하는 유저가 낮 이벤트를 놓치지 않도록 시간대를 12시간 반전하는 옵션 제공. (세세한 시간 커스텀까지는 불필요)

## 5. 이벤트 시스템
*   **모금:** 하루 1회 필수. 분수대에서 진행.
*   **장소별 이벤트 풀:** 각 장소에 성격에 맞는 이벤트 풀을 배정. 원작처럼 고정 시간대가 아닌 **랜덤 발생**.
*   **관찰/참여:** 이벤트 성격에 따라 다름 (관찰만 하는 것, 플레이어가 참여할 수 있는 것).
*   세부 이벤트 목록은 장소 확정 후 설계. 원작 이벤트 참고는 [07-research.md](07-research.md).

## 6. 미니게임
두 트랙으로 구분. 구체적인 게임 목록은 추후 설계.

### 관찰형 (캐릭터끼리)
*   플레이어는 구경만. 결과가 관계/기분에 영향.
*   예시 방향: 끝말잇기, 랩 배틀, 가위바위보, 요리 대결 등.

### 참여형 (플레이어 + 캐릭터)
*   캐릭터가 "나랑 놀아줘" 말풍선으로 유도. 간단한 터치/클릭 기반.
*   원작 참고: 모기 잡기, 무궁화 꽃이 피었습니다 등.
*   새로운 미니게임을 독자적으로 기획.
