### 성격 결정: 5개 슬라이더

| 슬라이더 | 양 극단 |
|---------|---------|
| Movement (動き) | 느림 ↔ 빠름 |
| Speech (話し方) | 유순함 ↔ 직설적 |
| Expressiveness (表情) | 냉정 ↔ 감정적 |
| Attitude (気持ち) | 진지 ↔ 여유 |
| Overall (全体的) | 기이함 ↔ 평범 (판정 무관) |

Movement+Speech 합산 × Expressiveness+Attitude 합산으로 16가지 유형 결정.

### 각 계통 특성 요약

- **나고미계**: 여유롭고 친절, 감수성 풍부, 순수
- **노리계**: 자발적, 충동적, 흥분하기 쉬움, 낙관적
- **쿨계**: 차분하고 신중, 논리적
- **드라이계**: 추진력, 경쟁적, 목표 지향적

### 말버릇 5종류

| 종류 | 일본어 | 사용 상황 |
|------|--------|----------|
| 일반 말버릇 | 口ぐせ | 평소 대화 |
| 기쁜 말버릇 | ハッピーフレーズ | 좋은 일 발생 |
| 화난 말버릇 | 怒りフレーズ | 싸움/충돌 후 |
| 슬픈 말버릇 | 悲しいフレーズ | 이별/거절 |
| 걱정 말버릇 | 心配フレーズ | 불안/걱정 |

각 16자까지 자유 입력 가능.

### 미니 개성 (プチ個性) — Switch판 신규

| 카테고리 | 예시 |
|---------|------|
| 걷는 방식 | 떠다니듯 걷기, 리듬 타며 걷기 등 |
| 먹는 방식 | 두근두근하며 먹기, 냄새 맡고 반응 등 |
| 자는 방식 | 뒤척이기, 땀 닦기 등 |
| 서있는 자세 | 키자한 포즈, 안절부절 등 |
| 말버릇 | (말버릇 시스템에 통합) |

## 2. 관계 시스템

### 관계 종류

**우정 계열:**
| 관계 | 일본어 | 영어 | 설명 |
|------|--------|------|------|
| 지인 | 知り合い | Acquaintance | 기본 상태 |
| 친구 | 友達 | Friend | 긍정적 교류 누적 |
| 베스트 프렌드 | 親友 | Best Friend | 장기간 높은 호감도. 절대 싸우지 않음 |

**연애 계열:**
| 관계 | 영어 | 설명 |
|------|------|------|
| 약한 짝사랑 | A little sweet on | 한쪽 감정 |
| 강한 짝사랑 | Totally smitten | 강한 일방적 감정 |
| 연인 | Sweetheart | 고백 성공 |
| 부부 | Married | 프로포즈 성공 |

### 호감도 7단계 색상 (내부)

| 단계 | 색상 | 상태 |
|------|------|------|
| 7 | 진한 초록 | 최상의 관계 |
| 6 | 초록 | 매우 좋음 |
| 5 | 연두 | 좋음 |
| 4 | 노랑 | 보통 |
| 3 | 주황 | 기본값 |
| 2 | 분홍/빨강 | 나쁨 |
| 1 | 보라 | 최악 |

### 싸움 시스템 (원작)

- **일반 싸움**: 한쪽이 사과 → 성공/실패
- **격렬한 싸움** (Life 한정): 공통 친구 제3자가 중재 필요. 발생률 매우 낮음. 불꽃 오라 + 헤비메탈 BGM 연출

### 삼각관계

1. A가 B에게 고백하려는 순간 C가 난입
2. "내가 더 좋아해!" 선언
3. B가 선택 → 거절된 쪽은 실망

### 질투 모드 (일본/한국/대만판 한정)

- 거절, 이별, 삼각관계 패배 시 발동
- 초록색 히토다마 연출
- "저 커플 헤어지게 해줘" 요청 가능

### 호감도 변동 요인

**증가:** 여행 티켓(1~2단계 즉시 상승), 대화 성공, 생일 선물
**감소:** 대화 실패/말다툼, 싸움 방치

### 특이사항
- 베스트 프렌드는 연인 불가 (원작)
- 이별 후 재결합 가능 (Life)
- 아이가 집에 있으면 이혼 불가 (원작)

## 3. 장소별 이벤트

### Collection (NDS) 시설 목록

Mii 아파트, 시청, 의류점, 리사이클숍, 식료품점, 인테리어점, 분수대, 랭킹보드, 상성진단, Mii뉴스, 질문홀, 직업진단

### Life (3DS) 시설 목록

**본섬:** 아파트(최대 100명), 전망대, 의류점, 모자점, 식료품점, 분수대, 상성진단, 랭킹보드, 시청, 부두/캠프장
**레저 섬:** 카페, 사진관, 놀이공원, 공원, Mii뉴스, 해변, 콘서트홀

### 주요 이벤트

**분수대:**
- Morning Market (6:30AM~12PM) — 50% 할인 음식 판매
- Rap Battle (NA/EU) — 두 Mii가 랩으로 디스
- Word Chain (JP/KR/EU) — 끝말잇기
- Donations — 하루 1회 모금

**공원:**
- Flying Disc (8AM~9AM)
- Afternoon Market (12PM~2:30PM)
- BBQ (2:30PM~3:30PM)
- Photo Shoot (4PM~5PM)

**놀이공원:**
- Magic Show (10AM~11AM)
- Tomodachi Quest (2:30PM~4:30PM, 9PM~11PM) — 레트로 RPG, 음식 몬스터와 배틀
- Night Market (5PM~9PM) — 미스터리 백

**해변:**
- Judgment Bay — 최대 4개 선택지 투표
- 자유 활동 (산책, 모래성 등)
- 고백 장소

**아파트:**
- 문제 해결 (고민 상담)
- 꿈 이벤트
- 비밀 편지 (변장한 발신자가 사소한 말 한마디)
- 레벨업

### 꿈 이벤트 유형 (15+가지)

슈퍼히어로, 숭배 의식, 거울, 드라이브, 숨바꼭질, 바다 괴물, 붉은 실, 왕족, 닌자, 진정한 사랑, 황당한 일, 문, 해조류, 소라게 등

### 병맛 하이라이트

- **음식 반응**: 최애 음식 → 로켓 발사, 두 번째 → 브레이크댄스, 최악 → 녹아내림
- **비밀 편지**: 변장한 캐릭터가 사소한 한마디만 하고 사라짐
- **Mii 뉴스**: 사소한 일을 중대 사건처럼 보도
- **꿈**: "스프링롤이여 만세!" 숭배, "봄 양파의 힘으로 변신!"
- **Tomodachi Quest**: 포크, 스시와 진지하게 RPG 배틀

## 4. Mii 생성 과정

### 생성 흐름 (Life 3DS)

```
외형 편집 (Mii Maker)
  얼굴형 → 피부색 → 헤어 → 눈썹 → 눈 → 코 → 입 →
  주름/마킹 → 안경/수염/콧수염/점
       ↓
프로필 입력
  성 → 이름 → 닉네임 → 생일 → 좋아하는 색 → 혈액형(일/한판만)
       ↓
음성 설정
  프리셋 6종 또는 커스텀
  (Pitch / Speed / Quality / Tone / Accent / Intonation)
       ↓
성격 슬라이더
  Movement → Speech → Expressiveness → Attitude → Overall
       ↓
섬 입주 완료
```

### 외형 파츠 수 비교

| 파츠 | Collection | Life | Living the Dream |
|------|-----------|------|-----------------|
| 피부색 | 6 | 6 | 14 |
| 얼굴형 | 8 | 8 | 16 |
| 눈 | 48 | 60 | 증가 |
| 코 | 12 | 18 | 증가 |
| 입 | 24+입술색3 | 36+입술색5 | 증가 |
| 헤어 | 72 | 132 | 더 증가 |
| 머리색 | 8 | 8 | +서브컬러 |
| 눈썹 | 24 | 24 | 증가 |
| 귀 | 없음 | 없음 | **신규** |

### 프로필 항목 비교

| 항목 | Collection | Life | Living the Dream |
|------|-----------|------|-----------------|
| 성/이름 | O | O | O |
| 닉네임 | O | O | O |
| 생일 | O | O | O |
| 좋아하는 색 | O (12종) | O (12종) | O |
| 혈액형 | O | 일/한판만 | 미확인 |
| 성별 | 남/여 | 남/여 | 남/여/논바이너리 |
| 연애 대상 | 없음 | 없음 | 남/여/모두 |

### 음성 커스텀 파라미터

| 파라미터 | 설명 |
|---------|------|
| Pitch | 목소리 높낮이 |
| Speed | 말하는 속도 |
| Quality | 음성 선명도 |
| Tone | 문장 시작 시 음높이 |
| Accent | 문장 끝 음높이 |
| Intonation | 억양 패턴 (4종) |

### 생성 후 변경 가능 여부
외형, 이름, 생일, 좋아하는 색, 성별, 성격, 음성 — **모두 변경 가능** (Town Hall 또는 Mii 방에서).

## 5. 시리즈별 신규 요소 비교

### Collection → Life 추가 요소
- 결혼/출산/자녀 독립 세대 시스템
- 음악당 (그룹 합창)
- 레저 아일랜드 (카페, 공원, 놀이공원)
- 어른 스프레이
- StreetPass 여행자 시스템
- 감정 표현 세분화

### Life → Living the Dream 추가 요소
- 팔레트 하우스 공방 (아이템 직접 그리기)
- 펫 시스템
- 동성 연애 / 논바이너리 지원
- 프치 개성 (미니 개성)
- 아파트 → 개별 주택 + 최대 8명 동거
- 섬 커스터마이징
- 플레이어 직접 개입 강화 (캐릭터 집어서 배치)
