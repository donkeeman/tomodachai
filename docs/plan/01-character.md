# 캐릭터 시스템

## 1. 캐릭터 생성
*   **캐릭터 생성 흐름:** 외형 편집 → 프로필 입력 → 음성 설정 → 성격 설정 → 입주 완료.
*   **외형 (3D 로우폴리, 파츠 조립):**
    *   기본 바디 모델 1개 + 교체 가능한 파츠(머리, 눈, 코, 입 등).
    *   파츠 위치/크기 조절 가능 (원작처럼 눈코입 위치, 크기, 체형 등을 파라미터로 조절).
    *   에셋 제작: 블렌더 MCP 활용.
    *   애니메이션은 기본 바디에 공유 적용 → 24명분 개별 제작 불필요.
    *   파츠 수량은 점진 확대.
*   **프로필 설정 항목:**
    *   이름 (성 / 이름). 닉네임은 생성 시 입력하지 않음.
    *   생일 (→ 별자리 자동 도출, 생일 이벤트 트리거)
    *   혈액형 (A/B/O/AB)
    *   좋아하는 색 (기본 복장 색상 결정)
    *   성별
*   **혈액형·별자리 활용:** 단순 장식이 아닌 **관계 영향 인자**로 활용. 궁합 시스템에 성격 + 혈액형 + 별자리가 복합적으로 영향.

## 2. 별명 시스템 (이벤트 기반)
*   캐릭터 간 친밀도가 일정 수준에 도달하면 "별명 지어줘도 돼?" 이벤트 발생 → 플레이어가 별명 입력.
*   캐릭터마다 서로 다른 별명을 부를 수 있음 (A는 B를 "철수"로, C는 B를 "수수"로 부르는 등).
*   LLM이 대사 생성 시 관계 단계와 별명 데이터를 참조하여 호칭 반영.

## 3. 성격 시스템
*   **16가지 고정 성격 유형:** 원작과 동일한 4계통(나고미/노리/쿨/드라이) × 4형 = 16가지. 향후 여유가 되면 하위 분기 형태로 확장 가능.
*   **성격 설정 방식 (슬라이더 기반):**
    *   **슬라이더 5개** (각 0~8):
        *   Movement (느림 ↔ 빠름) — 행동 속도에 영향
        *   Speech (유순함 ↔ 직설적) — 말투에 영향
        *   Expressiveness (냉정 ↔ 감정적) — 감정 표현에 영향
        *   Attitude (진지 ↔ 여유) — 태도에 영향
        *   Overall (특이 ↔ 평범) — 성격 유형 판정에는 무관. 병맛 이벤트의 톤 강도 및 내용의 기이함 정도에 영향. 특이 쪽이면 이벤트 내용 자체가 황당해지고, 평범 쪽이면 일상적인 범위 내에서 전개.
    *   **유형 결정:** Movement+Speech 합산 → 4계통 결정, Expressiveness+Attitude 합산 → 4형 결정. 구간은 균등 분할. Overall은 유형 판정에 불참.
    *   **슬라이더 세부 값의 역할:** 유형이 같아도 슬라이더 수치에 따라 행동/말투의 강도가 다름. LLM 프롬프트에 강도 정보로 전달.
    *   **자연어 입력 보조:** 유저가 텍스트로 성격을 설명하면, LLM이 분석하여 슬라이더 값을 자동 세팅. 이후 수동 미조정 가능.
    *   결과물은 항상 슬라이더 값(= 16가지 유형 중 하나)으로 귀결되어 시스템 일관성 유지.

## 4. 기분/만족도 시스템
*   **만족도(행복도):** 캐릭터별 내부 수치 (0~100).
    *   좋아하는 것(음식, 옷 등)을 주면 상승, 싫어하는 것을 주거나 방치하면 하락.
*   **경험치/레벨업:**
    *   경험치는 틱마다 누적. 만족도가 경험치 획득 배율로 작동 (만족도 높으면 많이 받고, 낮으면 적게 받거나 깎임).
    *   경험치 누적 → 레벨업 → 플레이어가 보상 선택 (아이템 / 말버릇 / 노래 / 인테리어 중 택1).
    *   레벨 구간/경험치 수치는 구현 단계에서 조정.
*   **배고픔:** 시간 경과에 따라 배고픔 발생. 음식을 주면 해소. 배고프면 만족도 하락.

## 5. 캐릭터별 선호도
*   **생성 시 랜덤 부여.** 플레이어가 먹여보거나 입혀보면서 발견하는 재미.
*   **음식 선호도:** 최애 / 좋아함 / 보통 / 싫어함 / 최악 단계. 반응 차이 (최애 → 로켓 발사급 리액션, 최악 → 녹아내림 등).
*   **의류 선호도:** 스타일/색상 취향.
*   **인테리어 선호도:** 방 꾸미기 취향.

## 6. 노래 시스템
*   **멜로디:** 장르별 템플릿 미리 제작. 캐릭터에게 노래를 선물로 부여.
*   **장르:** 트로트(엔카), 아이돌, 발라드, 락(메탈 포함), 랩, 뮤지컬/오페라, 동요, 찬송가/장엄한 풍.
*   **가사 설정 (4가지 방식):**
    1. 기본값 가사 (장르별 기본 제공)
    2. 단어 하나하나 직접 지정 (원작 방식)
    3. 분위기 입력 → LLM 생성 ("슬픈 느낌으로", "짝사랑 노래" 등)
    4. 랜덤 버튼 → LLM 랜덤 생성
*   **솔로 / 듀엣 / 그룹:**
    *   같은 장르의 노래를 가진 캐릭터 2명 이상이면 합동 공연 가능.
    *   **파트 배정:** 플레이어가 직접 지정 (1절 A, 2절 B, 후렴 같이 등) 또는 자동 배정.
    *   조합에 따른 재미 (베프끼리, 원수끼리 등).
*   **출력:** TTS로 가사를 읽어줌. 콘서트홀 등에서 공연 이벤트로 활용.
*   **BGM 스타일:** 레트로 지향. DS/3DS 사운드폰트 또는 로우파이 중 검토 중. (TODO)

## 7. 미니 개성
*   성격 유형과 별개로, 걷는 방식·먹는 방식·습관적인 말 등 미세한 행동 특성을 캐릭터별로 부여.
*   LLM 프롬프트에 행동 특성 필드로 주입하여 대사/행동 묘사에 자연스럽게 반영.

## 8. 말버릇 시스템
*   **5종류 (감정별):** 일반 / 기쁠 때 / 화날 때 / 슬플 때 / 걱정할 때. 각각 별도 설정.
*   **입력 방식:** 플레이어가 직접 입력 가능. 자동 생성 옵션도 제공 (성격 기반으로 LLM이 추천).
*   **LLM 반영 방식:** 단순히 문장 끝에 붙이는 것이 아니라, LLM이 문맥에 맞춰 대사에 자연스럽게 녹여서 출력. 말버릇이 대화 흐름 속에 유기적으로 섞이도록 프롬프트 설계.

## 9. 병맛/초현실 요소 (하이브리드 방식)
원작의 핵심 매력인 소소한 병맛 유머를 적극 반영.
*   **비주얼/연출 병맛:** 꿈 시퀀스, 과장된 리액션 애니메이션 등은 미리 만든 이벤트 템플릿 풀로 제공.
*   **텍스트/서사 병맛:** LLM이 프롬프트 기반으로 매번 새로운 엉뚱한 대사/상황을 생성.
*   **조합:** 미리 만든 연출 틀 + LLM이 생성한 텍스트를 끼워넣는 방식 (예: "꿈 시퀀스 연출 템플릿" + LLM이 생성한 꿈 내용).
