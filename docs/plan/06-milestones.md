# 단계별 구현 마일스톤

## Phase 1: AI 코어 프로토타입 (텍스트 기반, Python)
*   16가지 성격 프롬프트 설계 및 LLM 매핑 로직 검증.
*   하이브리드 관계 관리 시스템 구축 (숫자 테이블 + 이벤트 로그 + LLM 대사 생성).
*   관계 단계(모르는 사이 → 결혼) 및 관계의 자유성(재결합 등) 시나리오 테스트.
*   미니 개성·말버릇이 LLM 출력에 반영되는지 검증.
*   맥락 선별 주입 전략 실험 (우선순위 기반 프롬프트 구성).
*   모든 결과는 텍스트 로그 중심으로 확인.

## Phase 2: 백엔드 API + 웹 시각화 기초 (FastAPI + Web)
*   JSON 기반 통신 규약 확립 (대사, 감정, 행동 상태, 관계 데이터 전송).
*   웹 프레임워크 선정 (Phaser / Three.js / Canvas 중 결정) 및 캐릭터 렌더링.
*   공간 시스템 기초 구현 (개별 주택, 공동 구역 배치).
*   실시간 시간 연동 + 오전/오후 반전 모드.
*   반응형 레이아웃 (PC + 모바일).

## Phase 3: 게임 루프 및 콘텐츠 시스템
*   공동 구역 이벤트 풀 구축 (분수대 이벤트 등 랜덤 이벤트).
*   병맛 요소 하이브리드 시스템 (비주얼 템플릿 + LLM 텍스트 조합).
*   AI 동네 뉴스 / AI 주민의 꿈 생성 연동.
*   펫 시스템 구현.
*   플레이어 개입 시스템 (상담, 물리적 간섭).
*   AI 자율성·이벤트 빈도 조절 옵션.

## Phase 4: 확장 및 마무리 (Polish)
*   다중 섬 시스템 (섬 생성, 캐릭터 분리 배치).
*   TTS 음성 시스템 연동.
*   로컬 데이터 저장 및 BYOK/로컬 LLM 설정창.
*   이벤트 풀·병맛 템플릿 양적 확보.
