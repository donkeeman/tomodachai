# Design Context — 별빛 마을 (Tomodachai)

> frontend-design 외 디자인 스킬이 참조하는 프로젝트 디자인 컨텍스트.

## Target audience
코지 관찰형 라이프시뮬을 즐기는 캐주얼 플레이어. 친구모아 아일랜드/동물의 숲 팬층.
"내가 만든 주민들이 마을에서 살아가는 걸 지켜보고 가끔 챙겨주는" 잔잔한 플레이.

## Use cases
- 캐릭터(주민) 생성·외모 커스터마이즈
- 마을(3D)에서 주민들을 관찰, 선택해 상태(기분/만족도/관계/도감) 확인
- 먹이 주기·도구 주기 등 가벼운 상호작용, 말풍선(고민/꿈) 응답
- 앨범(사진/요리), 랭킹보드 열람

## Brand personality / tone
**아기자기·아늑한(cozy) 캔디·젤리 게임** — 친구모아 라이프풍.
슬릭한 "웹앱/웹게임"이 아니라 **손에 잡히는 휴대용 게임기** 느낌의 토이 UI.

### Aesthetic direction: 캔디·젤리 (toy/jelly)
- **아웃라인**: 모든 칩/패널/버튼에 툭툭한 다크 테두리(2.5~3px, 잉크 브라운). 스티커처럼 씬 위에 얹힌 느낌.
- **모서리**: 깊게 굽은 둥근 모서리(18~22px), 작은 칩은 999px 알약.
- **패널**: 반투명 흰색 금지 → **솔리드 cream/candy** 배경 + 청키 드롭섀도(오프셋 큼·블러 작음) + 상단 젤리 하이라이트.
- **버튼**: 캔디 알약 + 하단 두께(box-shadow 엣지). 누르면 아래로 가라앉음(translateY + 엣지 축소). 바운스/elastic 금지(스냅 ease-out).
- **게이지**: 청키 라운드 바 + 아웃라인.

### Palette (tinted neutrals, no pure black/white)
- 잉크(텍스트/아웃라인): `--ink #4a3526`, 약한 톤 `--ink-soft #8a715c`
- 크림(패널/배경): `--cream #fffaf0`, `--cream-deep #ffefd6`
- 민트(주색/잎): `--mint #7ed0a4`, `--mint-deep #45b487`
- 핑크(캔디 강조): `--pink #ff9ec7`, `--pink-deep #ff7eae`
- 버터(보조 강조): `--butter #ffd98e`
- 중립은 전부 cream/brown 쪽으로 틴트(회색 금지).

### Typography
- **디스플레이(제목/주민 이름/버튼)**: `Jua` — 청키하고 동그란 한글 디스플레이 폰트(친구모아 톤). Google Fonts.
- **본문**: `Pretendard`(기존) 유지 — 깔끔한 한글 가독.
- Inter/Roboto/system/monospace 금지.

## Constraints
- Svelte 5 + Babylon.js 3D 위 오버레이 UI. 전역 스타일 `src/styles.css` + 컴포넌트 scoped.
- 3D 씬은 이미 소프트 파스텔 저폴리(아기자기) — UI가 그 톤과 한 몸이 되어야 함.
- 프로토타입: 폰트는 Google Fonts link 허용(추후 Tauri 오프라인 시 번들).
